# Task 3 - Causality Assessment

## Case Study 1
- Patient: 45-year-old Female
- Suspected Drug: Amoxicillin
- Adverse Reaction: Skin Rash
- Onset: 2 days after starting the drug
- Outcome: Recovered after stopping the drug

## Assessment Criteria (WHO-UMC Scale)
1. Temporal Relationship: YES - Reaction occurred after drug administration (2 days)
2. Dechallenge: POSITIVE - Patient recovered after stopping the drug
3. Rechallenge: NOT DONE
4. Alternative Causes: NO - No other cause found

## Causality Classification
Final Assessment: PROBABLE

Reason: 
- Plausible temporal relationship present
- Positive dechallenge
- No alternative cause identified
- Rechallenge not required for Probable category
- As per standard causality methods (Certain, Probable, Possible)
